# Sistema Bancário Simples (Java)

Projeto simples em Java via console feito para fins educacionais e prática de conceitos básicos de Programação Orientada a Objetos (POO).

## Funcionalidades

- **Registro de Usuário:** Cadastro de nome de titular e senha.
- **Login:** Autenticação de titular e senha cadastrados.
- **Depósito:** Adicionar saldo à conta.
- **Saque:** Retirar saldo com validação de limite.
- **Consulta de Saldo:** Visualizar saldo atual.

## Como Executar

### Pré-requisitos
- JDK instalado (Java Development Kit versão 8 ou superior).

### Passos

1. Compile os arquivos Java:
```bash
javac src/*.java -d bin
```

2. Execute o programa:
```bash
java -cp bin Banco
```

*(Ou execute direto pela sua IDE de preferência, como IntelliJ IDEA).*
